# Windows 크롬: 즐겨찾기로 상품 자료 가져오기

현재 북마클릿 버전은 **2026-10-28.3**이다. 기존 즐겨찾기는 자동 갱신되지 않으므로 삭제하고 새로 등록해야 한다. [자동 상품 영역 탐색·이미지 분류·리뷰 구분·Windows 재검증 안내](smartstore-automatic-extraction.md)를 따른다. 직접 선택은 예외 보조 수단이며 자동 추출 성공으로 집계하지 않는다. 실제 운영 상품 검증이 완료됐다는 뜻은 아니다.

Windows에서 처음 실행하는 경우에는 먼저 [설치·실행 안내](windows-browser-import-test.md)를 따른다.

## 사용 순서

1. 최신 소스의 ClipForge를 실행하고 **상품 보관함 → 즐겨찾기로 상품 가져오기**를 연다. 주소는 `/products/browser`이다. 이전에 설치한 Windows 실행 파일에는 이번 소스 변경이 자동 적용되지 않는다.
2. 크롬에서 **Ctrl + Shift + B**를 누르고 화면의 **상품 가져오기** 버튼을 즐겨찾기 모음으로 끌어 놓는다. 실패하면 **Ctrl + Shift + O → ⋮ → 새 북마크 추가**에서 이름을 입력하고, 화면의 수동 등록용 코드 전체를 URL로 붙여넣는다.
3. 네이버 쇼핑커넥트 또는 쿠팡 제휴 링크를 직접 열어 실제 상품 페이지에 도착한다. 원본 제휴 링크는 따로 보관한다. 네이버 스마트스토어·브랜드스토어와 쿠팡의 실제 상품 주소를 지원한다.
4. 구매할 옵션을 먼저 선택한다. 상세정보와 필요한 구매평을 직접 펼친 후 즐겨찾기의 **상품 가져오기**를 누른다. 프로그램은 자동 스크롤, 추가 리뷰 조회, 로그인, iframe 접근, 인증 우회를 하지 않는다.
5. 페이지 안 확인창의 한국어 입력칸에서 상품·옵션·설명·구매평을 확인하고 수정한다. 구매평에 이름·주소 등 개인정보, 안내 문구, 다른 상품 내용이 있다면 제거한다. 이미지 미리보기에서 가져올 사진만 선택한다. 확인란을 체크하고 **확인한 자료 파일 저장**을 누른다.
6. ClipForge `/products/browser`에서 다운로드한 `clipforge-product.json`을 연다. 파일을 열면 한국어 입력칸에 자료가 표시된다. 필요하면 내용을 수정한다. 사진을 다시 선택할 수 있다. 원본 제휴 링크를 입력하면 별도로 보존한다. 짧은 제휴 링크가 같은 상품을 가리키는지는 직접 확인해야 한다.
7. 확인란을 체크하고 **확인한 자료 가져오기**를 누르면 기존 상품 검토 화면으로 이동한다. 부족한 상품명·가격·옵션·특징을 보완하고 사용할 이미지를 확인한다. 다운로드가 거부된 사진은 사용 권한이 있는 파일로 직접 업로드한다.
8. 상품 정보·이미지 영상 사용 권한 확인란을 체크하고 **확인한 상품 저장**을 누른다. 상품 보관함에서 다시 열거나 기존 제작 기능으로 연결할 수 있다. 링크 가져오기 자체로 영상 제작은 시작되지 않는다.

## 수집 범위와 정확성

- 렌더링된 상품 전용 DOM과 현재 상품의 공개 head 메타데이터를 관찰한다. 이미지·구매평은 현재 화면 영역에 표시된 요소만 사용하며 이미지는 로드 완료를 추가 확인한다. 화면 밖·미로드 이미지는 제외한다. 숨김 요소, 페이지 내부 상태 스크립트, 쿠키, 저장소, 인증 헤더, 리뷰 작성자 요소는 읽지 않는다. 공개 메타데이터 상품명·가격·브랜드는 참고 후보로 구분한다.
- 상품명·가격·브랜드·선택 옵션·설명·표 사양·대표/상세 이미지·명시적 리뷰 본문·평점·영상 요소 존재 여부를 지원한다. 사이트 구조가 맞지 않거나 내용이 이미지/iframe 안에 있으면 미확인으로 남긴다. OCR과 숨겨진 API 호출은 없다.
- 일반 본문을 구매평으로 추정하지 않는다. 리뷰 본문 전용 선택자만 사용하지만 플랫폼 변경으로 오분류될 수 있어 사용자 검토가 필수다. 실제 구매 인증 여부를 증명하지는 않는다.
- 동일 URL/알려진 크기 변환 쿼리 차이의 이미지와 공백 정리 후 동일한 리뷰를 중복 제거한다. 시각적 이미지·의미적 문장 중복 판정은 아직 없다. 대표·상세 사진을 별도 의미 분류하지는 않는다.
- 쿠팡 상품·itemId·vendorItemId를 유지한다. 다른 상품/옵션의 직접 제휴 URL 결합은 거부한다. 네이버 선택 옵션은 표시된 텍스트만 기록한다. 모든 구매평과 평점은 **상품 단위, 옵션 일치 미확인**으로 보관하며 옵션별 사양에 자동 합치지 않는다.
- 인식 가능한 이메일·휴대전화 번호는 제거한다. 자유 서술 안의 이름·주소 등 모든 개인정보를 자동으로 식별한다고 보장하지 않는다. 저장 전에 사람이 제거해야 한다. 인증 관련 이름의 URL 매개변수는 페이지 주소에서 제외하고 가져오기 입력에서 거부한다.
- 출처와 수집 시각을 스냅샷 단위로 기록한다. 원본의 모든 항목은 같은 출처·수집 시각을 공유한다. 편집한 상품 정보와 서버 보존 원본은 분리된다. 파일 제공자가 수집 시각과 내용을 바꿀 수 있으므로 진위 인증 자료는 아니다.

## 전송·권한·영상

- 북마클릿은 `fetch`, XHR, 비콘, 다른 서버/ClipForge로 전송을 하지 않는다. JSON은 사용자가 확인 후 파일로 저장한다. 이미지 미리보기는 원래 이미지 URL을 불러오므로 해당 이미지 서버에 요청할 수 있다. ClipForge에서는 **확인한 자료 가져오기**를 누른 때만 자료를 서버에 보낸다.
- 상업 재사용·AI 입력·영상 다운로드·영상 편집은 별도 권한이며 원본 스냅샷에는 모두 `unconfirmed`로 기록한다. 체크박스는 사용자 확인 기록이며 플랫폼이나 저작권자의 허가를 대신하지 않는다. 페이지를 볼 수 있다고 리뷰·사진·영상을 광고에 쓸 수 있는 것은 아니다. 북마클릿 제공 자체가 플랫폼 이용 조건의 허용을 보증하지 않는다.
- 영상은 **요소 존재 여부만** 수집한다. 실제 재생 가능성, 다운로드 가능성, 라이선스는 미확인이다. 영상 URL·스트림·토큰을 추출하거나 다운로드하지 않는다. 권한이 확인된 영상 파일은 기존 제작 화면의 로컬 자료 기능으로 직접 추가한다. 상품별 영상 파일 연결과 자동 편집은 후속 개발이다.
- 구매평 원문은 참고 자료로만 보관한다. AI 분석이나 광고 원문 전재는 실행하지 않는다. 기존 영상 제작 엔진은 이 자료를 자동으로 AI에 보내지 않는다.
- 종료된 네이버 쇼핑 검색 API는 인증 설정이 있어도 호출하지 않도록 차단했다. 이번 기능은 공식 API 인증 없이 사용자 확인 자료를 가져오는 별도 경로다.

## 개발 검증

테스트는 네이버·쿠팡 예제 DOM, 중복·숨김·일반 안내/작성자 제외, 출처·옵션 보존, 사용자 확인, 위험 URL/과대 입력 거부, 서버 원본 저장을 검증한다. 실제 운영 페이지·로그인 계정·Windows 설치 파일 테스트를 대신하지 않는다. 플랫폼 CSP로 즐겨찾기 실행이 막히면 보안 설정을 끄거나 우회하지 말고 직접 입력/업로드를 이용한다.


2026-10-28 최종 검증: 전체 145개 테스트 파일, 1,431개 테스트 통과. 프로덕션 빌드와 TypeScript 검사 통과. 전체 lint 오류 0개(기존 경고 20개). Chromium에서 프로덕션 북마클릿 실행·쿠팡 자료 추출/중복 제거·자동 전송 없음·확인 후 파일 내보내기·한국어 수정/제휴 링크 보존·권한 확인/이미지 업로드/저장·보관함/서버 저장·다시 열기·네이버 자료 추출의 9개 흐름을 검증했다. 외부 플랫폼 페이지는 예제 HTML을 사용했고 사용자 자료와 분리한 임시 데이터 폴더로 테스트했다. 실제 판매자 운영 페이지와 Windows 설치 파일은 미검증이다. 위 검증 당시 GitHub 커밋/푸시 및 Windows 설치 파일 재배포는 하지 않았다. 이후 커밋 준비 상태는 `release-review.md`, Windows 실행 절차는 [Windows 실제 테스트 안내](windows-browser-import-test.md)를 확인한다.
