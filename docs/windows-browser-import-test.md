# Windows에서 상품 가져오기 직접 테스트하기

이 안내는 새 기능이 포함된 **소스 실행** 기준이다. 기존 Windows 설치 프로그램을 실행하거나 기존 GitHub Release를 내려받으면 이번 변경이 들어 있지 않을 수 있다. 이번 작업에서는 새 `.exe`를 만들거나 Windows에서 실행하지 않았다. 실제 네이버·쿠팡 페이지의 추출 성공도 아직 미검증이다.

## 1. 준비할 프로그램

| 프로그램 | 필요 여부 | 용도 |
| --- | --- | --- |
| Windows 크롬 | 필요 | 상품 페이지와 ClipForge 열기, 북마클릿 실행 |
| Node.js 22 최신 유지보수 버전 | 소스로 실행할 때 필요 | ClipForge 실행. 저장소 CI도 Node 22 기준 |
| pnpm 10.33.0 | 소스로 실행할 때 필요 | 프로젝트에 고정된 패키지 설치 도구 |
| FFmpeg와 FFprobe | 소스로 이미지 저장·영상 기능을 시험할 때 필요 | 실제 이미지 검사와 영상 처리 |
| Git | ZIP으로 받으면 불필요 | GitHub 브랜치를 직접 내려받을 때만 필요 |
| 네이버·쿠팡 API 키 / AI API 키 | 이번 가져오기 테스트에는 불필요 | AI 분석·생성은 별도 기능 |

Node.js는 https://nodejs.org/en/download 에서 **22.x 최신 버전 → Windows Installer → 본인 PC 구조(x64 또는 ARM64)**를 선택해 설치한다. 설치 후 명령 프롬프트 창을 새로 연다. Node 22용 네이티브 모듈이 다운로드되지 않으면 설치가 실패할 수 있다. 그런 경우 오류를 기록하고 중단한다. 이 안내의 Windows 설치 과정은 실제 실행 검증 전이다.

FFmpeg는 Windows 패키지 관리자가 있다면 아래 명령으로 설치할 수 있다. 설치가 끝나면 명령 프롬프트를 닫고 다시 연다.

```bat
winget install --exact --id Gyan.FFmpeg
```

`winget`이 없으면 https://ffmpeg.org/download.html 의 Windows 배포 안내에서 `ffmpeg.exe`와 `ffprobe.exe`를 포함한 패키지를 선택한다. 압축을 풀고 두 파일이 들어 있는 `bin` 폴더를 Windows 사용자 환경 변수 `Path`에 추가한 뒤 명령 프롬프트를 다시 연다. 아래 확인 명령에서 둘 다 버전이 나와야 한다.

## 2. 새 소스를 별도 폴더에 준비

**쉬운 방법: ZIP 사용**

[이번 기능이 들어 있는 GitHub 브랜치 ZIP 받기](https://github.com/omok424642-lgtm/clipforge/archive/refs/heads/feat/reviewed-browser-product-import.zip)

위 GitHub ZIP 또는 이 작업에서 제공한 `clipforge-review-source.zip`을 내려받아 압축을 푼다. GitHub ZIP의 최상위 폴더 이름은 다를 수 있다. 기존 프로그램 폴더를 덮어쓰지 않는다. 파일 안에 `package.json`과 `pnpm-lock.yaml`이 있는 `clipforge` 폴더를 사용한다. GitHub 인증 문제로 푸시되지 않은 경우에는 GitHub의 기존 main ZIP 대신 이 파일을 사용해야 변경 사항이 포함된다.

**Git을 사용하는 경우**

2026-10-28 이 브랜치는 GitHub에 푸시되었다. Git이 설치되어 있다면 아래 명령으로 받을 수 있다. main 병합이나 PR 생성 완료를 뜻하지 않는다.

```bat
git clone --branch feat/reviewed-browser-product-import --single-branch https://github.com/omok424642-lgtm/clipforge.git clipforge-browser-test
cd clipforge-browser-test
```

## 3. 설치하고 실행

Windows 키 + R → `cmd` → Enter로 **명령 프롬프트**를 연다. 아래 첫 줄의 경로는 실제 압축을 푼 폴더로 바꾼다. Git으로 받았다면 이미 해당 폴더에 있으므로 첫 줄은 생략한다. PowerShell 실행 정책을 변경할 필요는 없다.

```bat
cd /d "C:\실제로 압축을 푼 경로\clipforge"
node --version
npm install --global pnpm@10.33.0
pnpm --version
ffmpeg -version
ffprobe -version
pnpm install --frozen-lockfile
pnpm dev --hostname 127.0.0.1 --port 3100
```

`node`는 `v22.x`, `pnpm`은 `10.33.0`이어야 한다. 설치에는 인터넷 연결과 디스크 여유 공간이 필요하다. `pnpm install`이 실패하면 다음 단계로 넘어가지 말고 오류 메시지를 기록한다. 이 프로젝트에서는 `npm install`로 프로젝트 의존성을 설치하지 않는다. 위 `npm install --global`은 pnpm 설치용이다.

터미널에 준비 완료 표시가 나오면 크롬에서 **http://127.0.0.1:3100/products/browser** 를 연다. 실행한 명령 프롬프트 창은 계속 켜 둔다. 3100 포트가 사용 중이면 기존 프로그램을 임의 종료하지 말고 `--port 3101`로 바꾸고 브라우저 주소도 맞춘다. 보관함은 브라우저·주소·포트별로 달라지므로 이후에도 같은 주소를 쓴다. 시크릿 창 대신 일반 창을 권장한다.

## 4. 즐겨찾기 버튼 등록

1. 크롬에서 **Ctrl + Shift + B**로 즐겨찾기 모음을 표시한다.
2. ClipForge 화면의 **상품 가져오기** 버튼을 즐겨찾기 모음으로 끌어 놓는다.
3. 안 되면 **Ctrl + Shift + O → 오른쪽 위 ⋮ → 새 북마크 추가**를 선택한다.
4. 이름은 `상품 가져오기`, URL은 ClipForge 화면에서 **수동 등록용 코드**를 펼쳐 코드 전체를 복사해 붙여넣는다. URL이 `javascript:`로 시작해야 한다. 주소창에 붙여넣는 방식은 사용하지 않는다.

확장 프로그램 설치, 네이버 개발자 등록, 쿠팡 API 인증 설정은 필요하지 않다. Smart App Control, 크롬 보안 설정, 사이트 보안 정책을 끌 필요도 없다. 사이트 정책으로 실행이 막히면 직접 입력/업로드 경로로 진행한다.

## 5. 실제 상품 페이지에서 파일 저장

네이버와 쿠팡을 각각 따로 시험한다.

1. 본인이 발급받은 제휴 링크를 따로 보관하고 그 링크를 크롬에서 직접 연다. 최종 도착 화면이 네이버 스마트스토어·브랜드스토어 또는 쿠팡 **실제 상품 페이지**인지 확인한다. 지원하지 않는 도착 화면은 강제로 처리하지 않는다.
2. 구매할 옵션을 선택하고 페이지가 갱신될 때까지 기다린다. 필요한 상세정보와 구매평은 직접 펼친다. 다른 상품을 새로 여는 경우에는 이전 확인창을 닫고 다시 실행한다.
3. 즐겨찾기의 **상품 가져오기**를 누른다.
4. 확인창에서 상품명·가격·브랜드·옵션·설명·사양·구매평·평점을 실제 화면과 비교한다. 빈칸은 미확인이다. 직접 확인 가능한 내용만 보완한다.
5. 이름·주소 등 개인정보, 리뷰 작성 안내, 다른 상품 내용은 지운다. 구매평은 선택 옵션과 일치하는지 미확인이므로 옵션별 제품 사양으로 간주하지 않는다.
6. 미리보기에서 가져올 이미지만 선택한다. 이 선택은 이미지 사용 허락을 받았다는 뜻이 아니다.
7. 확인란을 체크하고 **확인한 자료 파일 저장**을 누른다. 다운로드 폴더에 `clipforge-product.json`이 생긴다. 두 번째 파일은 크롬에서 `(1)` 등 이름을 붙일 수 있다.

가격이 쿠폰가·옵션가·배송비 포함가인지 별도로 확인한다. 영상은 **요소 존재 여부만** 기록하며 실제 재생/다운로드/광고 활용 허락은 미확인이다. 이 버튼으로 영상을 다운로드하지 않는다.

## 6. ClipForge에서 검토하고 보관함 저장

1. ClipForge 탭의 **상품 자료 파일**에서 방금 저장한 파일을 선택한다.
2. 한국어 입력칸에서 내용을 다시 확인하고 수정한다. 필요하면 이미지 미리보기를 누르고 선택을 바꾼다. 미리보기는 이미지 서버에 요청할 수 있다.
3. 원본 제휴 링크를 보존하려면 해당 입력칸에 직접 넣는다. 짧은 제휴 링크가 같은 상품을 가리키는지는 직접 확인한다.
4. 확인란을 체크하고 **확인한 자료 가져오기**를 누른다. 이때 확인한 자료가 실행 중인 로컬 ClipForge 서버에 전달된다. 그 전에는 상품 자료 JSON을 서버에 자동 전송하지 않는다.
5. 기존 상품 검토 화면에서 필수 상품명·가격·옵션·특징과 이미지를 보완한다. 옵션이 정말 없으면 `옵션 없음`을 적는다. 이미지는 최소 1장 필요하다.
6. 다운로드가 제한된 이미지는 사용 권한이 있는 JPG·PNG·WebP 등의 파일을 직접 업로드한다. 권한이 없으면 영상용 이미지로 저장하지 않는다.
7. 상품 정보 확인과 **이미지 영상 사용 권한** 확인란을 체크하고 **확인한 상품 저장**을 누른다. 체크박스가 저작권자의 허락을 만들어 주지는 않는다.
8. **상품 보관함에서 확인하기**를 누른다. 상품 카드가 나타나는지, 새로고침해도 유지되는지, 원본 링크 확인을 눌렀을 때 출처·브랜드·구매평이 남아 있는지 확인한다.

이 단계에서는 대본·AI 구매평 분석·영상 제작·업로드가 자동 실행되지 않는다. 권한이 확인된 영상 파일은 기존 제작 화면의 로컬 자료 기능에서 별도로 추가한다.

## 7. 실제 테스트 결과 기록

아래 항목은 사용자가 실제로 확인하기 전까지 모두 **미검증**이다. 네이버·쿠팡별로 결과를 따로 기록한다. 오류를 전달할 때 쿠키·토큰·구매자 개인정보를 보내지 않는다.

| 확인할 항목 | 네이버 실제 페이지 | 쿠팡 실제 페이지 |
| --- | --- | --- |
| Windows 설치 및 실행 | 미검증 | 미검증 |
| 실제 제휴 링크 도착 페이지에서 버튼 실행 | 미검증 | 미검증 |
| 상품명·가격·브랜드·선택 옵션 일치 | 미검증 | 미검증 |
| 상세설명·사양 추출, 이미지 미리보기·선택 | 미검증 | 미검증 |
| 표시된 구매평·평점, 개인정보·안내 문구 제거 | 미검증 | 미검증 |
| 원본 제휴 링크 보존 | 미검증 | 미검증 |
| 권한 있는 이미지 저장 후 보관함 유지 | 미검증 | 미검증 |

종료는 명령 프롬프트에서 **Ctrl + C**이다. 재실행은 같은 폴더에서 마지막 `pnpm dev` 명령만 실행하면 된다. 브라우저 보관함과 소스 폴더의 `data`에는 자료가 있으므로 테스트가 끝나기 전에 삭제하지 않는다.
