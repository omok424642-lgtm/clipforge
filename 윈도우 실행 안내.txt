ClipForge 개인용 쇼핑클립 — Windows 실행 안내

이 폴더는 설치용 EXE가 아니라 웹앱 소스입니다.
처음 한 번 구성요소를 준비한 후, 평소에는 '쇼핑클립 시작하기.cmd'만 더블클릭합니다.
Windows 10/11과 최신 Node.js 22.x 사용을 권장합니다.
Windows에서의 실제 설치·더블클릭·크롬 자동 열기는 아직 직접 검증하지 않았습니다.

1. 처음 한 번 준비

  A. https://nodejs.org/en/download 에서 Node.js 최신 22.x Windows 버전을 설치합니다.
     최소 22.13 이상이 필요합니다. 본인 PC 구조에 맞는 설치 파일을 선택하세요.
     이미 조건을 만족하는 Node.js가 있으면 다시 설치할 필요가 없습니다.
  B. https://www.google.com/chrome/ 에서 크롬을 설치합니다.
  C. Windows 키 + R → cmd → Enter로 명령 프롬프트를 열고 아래 두 명령을 실행합니다.

       npm install --global pnpm@10.33.0
       winget install --exact --id Gyan.FFmpeg

     pnpm은 최초 설치와 앱 업데이트 때 사용합니다. FFmpeg 패키지에는 FFprobe도 필요합니다.
     winget이 없으면 https://ffmpeg.org/download.html 의 Windows 배포 안내를 이용하세요.
     ffmpeg.exe와 ffprobe.exe가 있는 bin 폴더를 사용자 환경 변수 Path에 추가해야 합니다.
     설치가 끝나면 명령 프롬프트를 닫습니다. PATH 변경은 새 창에서 적용됩니다.
  D. GitHub에서 이번 기능이 포함된 소스를 ZIP으로 내려받아 일반 폴더에 완전히 압축 해제합니다.
     Program Files 같은 쓰기 제한 폴더나 ZIP 안에서 실행하지 마세요.
     package.json, scripts 폴더, 두 CMD 파일이 함께 있어야 합니다.
     기존 ClipForge 폴더와 상품 자료를 덮어쓰거나 삭제하지 마세요.
  E. '처음 설치하기.cmd'를 더블클릭합니다.
     구성요소 설치와 실행 파일 빌드에 인터넷·디스크 공간과 수 분이 필요할 수 있습니다.
     '설치가 완료됐습니다'가 나올 때까지 창을 열어 둡니다.
     실패하면 오류가 표시되고 창이 남습니다. 아래 오류 안내를 확인하세요.

  이번 웹앱 설치는 Electron용 데이터베이스 재빌드를 하지 않습니다.
  pnpm dist, electron:rebuild, bundle:standalone 명령은 이 실행 방법에 필요하지 않습니다.
  필요한 프로그램을 설치하는 것 외에 관리자 실행·보안 기능 해제는 요구하지 않습니다.

2. 평소 실행과 종료

  A. '쇼핑클립 시작하기.cmd'를 더블클릭합니다.
  B. 준비가 끝나면 크롬이 자동으로 열립니다.
     시작 화면: http://127.0.0.1:3100/discover
     상품 보관함: http://127.0.0.1:3100/products
     즐겨찾기로 상품 가져오기: http://127.0.0.1:3100/products/browser
  C. 실행 중인 검은 창은 계속 열어 둡니다. 크롬 탭만 닫아도 서버는 계속 실행됩니다.
     앱을 종료하려면 실행 창에서 Ctrl + C를 누릅니다.
     Windows가 일괄 작업 종료를 묻는다면 Y를 입력합니다.
  D. 같은 폴더의 앱이 이미 실행 중이면 새 서버를 만들지 않고 크롬에서 다시 엽니다.
     시작 중에 다시 누르면 '진행 중' 안내가 나올 수 있으니 잠시 기다립니다.

  주소는 127.0.0.1로만 열어 내 PC에서 접속하도록 설정했습니다.
  공유기 포트 개방이나 공용 네트워크 서버 설정이 필요하지 않습니다.
  첫 화면 열기는 로컬이지만 AI 서비스·상품 이미지 등 기존 기능에는 인터넷이 필요할 수 있습니다.
  상품 가져오기 자체에는 네이버·쿠팡 API 키나 AI API 키가 필요하지 않습니다.

3. 자료 보존과 업데이트

  앱은 기본적으로 이 폴더의 data를 그대로 사용하며 자료를 자동 삭제하지 않습니다.
  상품 보관함 목록은 기존 방식대로 크롬 프로필과 웹 주소에도 연결됩니다.
  같은 크롬 일반 창과 http://127.0.0.1:3100 주소를 계속 사용하세요.
  localhost, 다른 포트, 시크릿 창, 다른 프로필에서는 보관함이 다르게 보일 수 있습니다.
  이전 EXE의 자료나 다른 주소의 보관함을 자동으로 옮기는 기능은 아닙니다.

  기존 웹앱의 data가 다른 폴더에 있다면 두 앱을 종료한 뒤 Windows의 사용자 환경 변수
  APP_DATA_DIR에 기존 data 폴더의 전체 경로를 지정할 수 있습니다.
  이미 APP_DATA_DIR / APP_MIGRATIONS_DIR을 설정했다면 그 값을 존중합니다.
  기존 폴더를 찾지 못했다고 자료를 삭제하거나 새 폴더로 덮어쓰지 마세요.

  소스를 업데이트하거나 Node.js의 큰 버전을 바꾼 뒤에는 실행 창을 먼저 종료하고
  '처음 설치하기.cmd'를 다시 실행합니다. '쇼핑클립 시작하기'가 필요한 경우 안내합니다.
  매번 구성요소를 다시 다운로드하거나 앱을 다시 빌드하지는 않습니다.
  실제 사용자 자료와 data 폴더는 GitHub에 올리지 않습니다.

4. 오류가 났을 때

  - Node.js 없음/버전 오류: 최신 22.x 설치 후 창을 닫고 다시 실행합니다.
  - pnpm 없음/버전 오류: npm install --global pnpm@10.33.0 실행 후 다시 설치합니다.
  - FFmpeg/FFprobe 없음: 위 패키지를 설치하고 새 명령 프롬프트에서
      ffmpeg -version
      ffprobe -version
    두 명령 모두 버전이 나오는지 확인합니다.
    별도 경로를 쓰면 사용자 환경 변수 FFMPEG_PATH, FFPROBE_PATH에 각 EXE의 전체 경로를 지정합니다.
    환경 변수 값에는 따옴표를 넣지 않습니다. FFmpeg에는 drawtext 기능이 필요합니다.
  - 크롬 없음: 크롬을 설치합니다. 특수 경로라면 사용자 환경 변수 CLIPFORGE_CHROME_PATH에
    chrome.exe 전체 경로를 따옴표 없이 지정합니다.
  - 3100 포트 사용 중: 다른 프로그램을 자동 종료하거나 포트를 바꾸지 않습니다.
    해당 앱의 실행 창을 직접 확인한 뒤 종료하고 재시도합니다.
  - 설치 중 오류: 인터넷과 디스크 공간을 확인합니다. 최신 Node.js 22.x를 권장합니다.
    SQLite를 직접 컴파일해야 하는 환경에서는 추가 Windows 빌드 도구가 필요할 수 있습니다.
    문제를 모르겠으면 오류와 로그를 확인한 뒤 진행하세요.
  - 쓰기 권한 오류: 내 문서 등 본인에게 쓰기 권한이 있는 폴더를 사용합니다.
  - 앱 준비 실패/갑자기 종료: 실행 창에 표시된 상세 로그 파일을 확인합니다.
  - 크롬이 안 열리지만 '준비 완료'가 나오면 위 127.0.0.1 주소를 직접 입력합니다.

  로그 위치: 이 폴더의 .clipforge-launcher\logs
  Node.js 설치 전 오류는 로그를 만들 수 없으므로 실행 창의 안내를 확인합니다.
  로그를 다른 사람에게 보낼 때 개인정보나 비밀 값이 없는지 먼저 확인합니다.

5. 상품 가져오기 직접 확인

  상품 가져오기 화면에서 즐겨찾기 버튼을 등록합니다.
  실제 네이버·쿠팡 상품 페이지에서 옵션 선택 → 자료 확인 → 파일 저장을 진행합니다.
  ClipForge에서 파일 열기 → 정보 수정 → 이미지 사용 권한 확인 → 보관함 저장을 진행합니다.
  자세한 설명: docs\browser-product-import.md, docs\windows-browser-import-test.md

  실제 네이버 쇼핑커넥트·쿠팡 운영 페이지에서의 추출 성공, Windows에서의 전체 설치·실행,
  Windows 크롬 자동 열기, Windows에서의 실제 MP4 제작은 아직 미검증입니다.
  영상 다운로드·구매평 AI 분석 기능이 이번 시작 파일에 추가된 것은 아닙니다.
