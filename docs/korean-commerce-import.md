# 네이버·쿠팡 상품 가져오기

## 이번 단계의 범위

`/products`의 **네이버·쿠팡 상품 가져오기** → `/products/import`에서 링크 분석,
상품 정보 검토·직접 보완, 이미지 선택·업로드, 확인 후 저장까지 처리한다.
영상 대본·음성·자막·합성 엔진은 변경하지 않는다. 자동 영상 제작도 시작하지 않는다.
기존 자동 링크 수집 API에 네이버·쿠팡 주소를 넣으면 409와 검토 화면 경로를 반환한다.

지원 주소:

- 네이버: `smartstore.naver.com/{store}/products/{id}`, 모바일 스마트스토어,
  `brand.naver.com/{store}/products/{id}`.
- 네이버 제휴/공유 후보: `naver.me`, `shoppingconnect.naver.com`,
  `brandconnect.naver.com`, `link.naver.com`의 경로가 있는 HTTPS 주소.
  단축 링크만으로 쇼핑커넥트 발급 여부나 상품 연결을 인증하지 않는다.
- 쿠팡: `www.coupang.com/vp/products/{id}`, `m.coupang.com/vm/products/{id}`,
  `link.coupang.com/a/{code}` 및 제휴 매개변수가 있는 상품 주소.

입력한 원본 URL의 쿼리 순서·인코딩·제휴 식별자를 수정하지 않는다.
별도 상품 주소/이동된 주소는 `resolvedUrl`에 저장한다. 짧은 제휴 링크를
해결하지 못하면 사용자가 실제 상품 주소를 별도로 입력한다. 두 주소의 관계는
최종 검토 시 사용자가 확인하며, 프로그램이 관계를 인증했다고 표시하지 않는다.

## 공식 연동 및 이용 조건 조사 상태

2026-10-27 이 환경에서 아래 공식 사이트를 직접 조회했으나 **egress proxy의
403 Forbidden**으로 문서 본문을 받지 못했다. 따라서 최신 API 계약, 쇼핑커넥트
파트너별 제공 범위, 데이터 저장/재사용 조건, 이미지 사용 허용 범위, 고지 문구의
적합성을 검증 완료했다고 주장하지 않는다. 실제 상품/API 조회도 미검증이다.

공식 확인 대상:

| 플랫폼 | 공식 출처 | 검토할 사항 |
| --- | --- | --- |
| 종료된 네이버 쇼핑 검색 API | https://developers.naver.com/notice/article/32530 | 2026-07-31 종료·별도 대체 API 없음. 호출 금지 |
| 네이버 API 이용 조건 | https://developers.naver.com/products/terms | 검색 결과 재사용, 출처 표시, 이미지/상업 이용 범위 |
| 네이버 커머스 API | https://apicenter.commerce.naver.com/docs/commerce-api/current | 인증 판매자 권한과 상품 상세/옵션 접근 범위. 타 판매자 상품을 자유롭게 조회하는 API로 간주하지 않음 |
| 네이버 쇼핑커넥트 | https://shoppingconnect.naver.com/ | 승인된 제휴 상품 정보 제공 경로, 이미지 허용 범위, 고지·클립 등록·태그 조건 |
| 쿠팡 파트너스 | https://partners.coupang.com/ | 승인된 파트너스 Open API 문서, 검색 계약, 이용/보관/광고 조건, 고지 기준 |
| 쿠팡 판매자 API | https://developers.coupangcorp.com/hc/ko | 판매자 인증 범위. 파트너스 검색 API와 별개임을 확인 |

쿠팡 파트너스 어댑터는 알려진 검색 API 형식에 기반한 **기본 비활성 연결 코드**다.
네이버 쇼핑 검색 API는 종료되어 설정·인증 정보가 있어도 호출하지 않는다.
최신 공식 문서와 승인된 계정으로 검증하기 전 운영에 활성화하지 않는다.
이번 작업에서 공식 API 인증 정보는 환경에 없었으며 값을 요청하거나 생성하지 않았다.
환경 설정 초안에는 조사·연동에 필요한 도메인만 추가했다. 저장된 초안은 실행 환경의
네트워크 정책 변경이나 게시를 뜻하지 않는다.

## 플랫폼별 수집 경로

### 네이버

네이버 쇼핑 검색 API는 **2026-07-31 종료되어 사용할 수 없다**.
종료 및 별도 대체 API가 없다는 공식 공지: https://developers.naver.com/notice/article/32530

코드에 남은 `collectNaver` 함수는 종료 안내만 추가하고 네트워크 요청을 하지 않는다.
기존 저장 데이터의 `naver_search_api` 식별자는 호환성을 위해 유지하지만 화면에는 종료 상태로 표시한다.
커머스 API는 판매자 권한 범위이며 임의의 쇼핑커넥트 상품 상세 조회 경로로 연결하지 않았다.
허용된 자료의 직접 입력·업로드를 사용한다. 현재 공식 계정으로 상품 조회 성공을 검증한 상태는 아니다.

### 쿠팡

파트너스 검색 어댑터는
`GET https://api-gateway.coupang.com/v2/providers/affiliate_open_api/apis/openapi/products/search`를
UTC 타임스탬프/HMAC-SHA256으로 서명한다. 원본에 선택 옵션 식별자가 있으면
`productId` 외에도 `itemId`·`vendorItemId`가 일치하는 상품 주소만 채택한다.
다른 옵션이나 유사 상품으로 대체하지 않는다. 반환된 제휴 주소로 원본을 덮어쓰지 않는다.
전체 옵션 목록·특징은 응답에 없으면 사용자가 보완한다.

### 공개 페이지의 보조 수집

공개 페이지 수집도 기본 비활성이다. 플랫폼 약관상 허용 범위를 확인한 뒤에만 사용한다.
허용된 경우에도 robots 정책을 먼저 확인하고 표준 Product JSON-LD/상품 메타데이터만
읽는다. 로그인·CAPTCHA·403·429를 우회하거나 브라우저 위장, 쿠키 이전,
프록시 회전, 비공개 내부 API 호출을 하지 않는다. 다른 플랫폼/내부 주소로의 이동을 막는다.
사용자 원본과 별도 입력 주소는 분리한다. robots 허용이 약관상 허용을 대신하지 않는다.

## 서버 설정: 공식 조건 확인 및 실제 계정 검증 후에만 활성화

서버 환경 변수 이름만 기재한다. 비밀 값은 브라우저, 저장 JSON, Git에 넣지 않는다.

- 네이버: 예전 환경 변수는 남아 있어도 종료된 쇼핑 검색 API를 활성화하지 못한다. 신규 인증 설정 불필요.
- 쿠팡: `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY`, `COUPANG_PRODUCT_API_TERMS_REVIEWED=1`
- 공개 메타데이터: 두 플랫폼의 허용 범위를 검토한 경우에만
  `COMMERCE_PUBLIC_METADATA_TERMS_REVIEWED=1`

플래그 설정 자체는 법적 허가나 API 승인을 만들지 않는다. 플래그와 인증 정보가 없으면
외부 페이지/API 요청 없이 링크 판별과 직접 입력 검토 기능을 제공한다.
API 실패 때 인증 정보나 원격 오류 응답 본문은 사용자에게 반환하지 않는다.
인증 헤더가 있는 요청은 리다이렉트를 따라가지 않는다.

## 정확성·이미지·저장

- 수집 시각, 수집 방식, 원본 링크, 상품 주소, 이미지 출처를 표시한다.
- 상품명·가격·선택 옵션·특징을 수정할 수 있다. 옵션이 없으면 ‘옵션 없음’을 명시한다.
- 수집 설명을 AI가 검증한 효능으로 바꾸지 않는다. 판매자가 표기한 속성만 참고 후보다.
- 원본을 열어 내용을 확인했다는 확인과 이미지 사용 권한 확인 후 저장한다.
- 플랫폼 CDN의 HTTPS 이미지 후보만 자동 저장한다. 리다이렉트/접근 제한은 거절한다.
  타입·파일 시그니처·최대 12MB·FFprobe로 실제 이미지 크기를 확인하고, 실패는 경고한다. 사용 가능한 이미지가 하나도
  없으면 최종 저장하지 않는다. 사용자 업로드도 파일 존재와 시그니처를 확인한다.
- 이미지 최대 10장. 후보 삭제·직접 업로드 가능. 다운로드 성공은 이용 허가를 뜻하지 않는다.
- `data/product-imports/{id}.json`: 수집 원본. `{id}.reviewed.json`: 확인·수정 최종본.
  별도 파일로 보관하여 사용자가 수정해도 수집 원본이 바뀌지 않는다.
- 이미지: `data/uploads/products/{id}/`. 상품 보관함은 기존 브라우저/데스크톱 저장 방식을
  유지하고, 원본·검토 메타데이터는 서버에도 저장한다. 다른 브라우저에서 보관함이
  자동 동기화되는 기능은 이번 범위가 아니다. 검토 URL로 서버 저장본은 다시 열 수 있다.

## 네이버 제휴 고지 설계

`disclosure.enabled`, 편집 가능한 `disclosure.text`,
`disclosure.placement = video_overlay`를 저장한다. 네이버 문구는 **초안**이며
플랫폼이 승인한 고정 문구라고 표시하지 않는다. 영상 합성에 실제 고지를 넣는 작업은
후속 단계다. 클립 업로드·쇼핑커넥트 태그 부착도 후속 단계이며 자동 수행하지 않는다.
기존 영상 제작 경로는 아직 이 메타데이터를 소비하지 않는다.

## 검증

고정된 Node 22/pnpm 10 환경에서:

```bash
export PATH=/workspace/.clipforge-tools/node_modules/.bin:$PATH
cd /workspace/clipforge
pnpm test src/lib/__tests__/commerce-product.test.ts src/lib/__tests__/commerce-images.test.ts --maxWorkers=1 --reporter=verbose
pnpm lint
pnpm build
```

자동 테스트는 종료된 네이버 API의 호출 차단 및 쿠팡 API의 모의 응답을 검사한다. 실제 계정 연동 성공을 뜻하지 않는다.
브라우저로 두 플랫폼의 링크 분석 → 직접 보완 → 이미지 업로드 → 확인 저장 → 새로고침 →
상품 보관함 표시를 검증했다. 이 과정에서 영상 생성 API가 호출되지 않음을 확인했다.
운영 활성화 전 실제 링크별 상품/옵션 일치, API 권한·조건, 이미지 허용 범위를 추가 확인해야 한다.

2026-10-27 최종 실행 결과: 전체 141개 테스트 파일 / 1,365개 테스트 통과
(신규 수집·검토·이미지·저장 테스트 54개 포함), 프로덕션 빌드 성공,
린트 오류 0개 / 기존 경고 20개. Chromium에서 두 플랫폼 모두 직접 입력·이미지 업로드·
검토 저장·새로고침 복원·상품 보관함 표시·원본 링크 보존을 확인했고 영상 생성 호출은 0회였다.
첫 전체 실행은 샌드박스의 로컬 서버 listen 제한으로 중단했으며,
로컬 서버 실행 권한을 확보한 최종 실행에서 전체 통과했다. 검증용 상품 파일만 정리했다.
