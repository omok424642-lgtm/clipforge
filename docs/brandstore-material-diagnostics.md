# 브랜드스토어 상세자료 진단 및 수정 (2026-10-28.4)

## 실제 진단 파일에서 확인한 사실

사용자가 제공한 2026-10-28.3 진단(상품 번호 13753702046)을 직접 읽었다.
문서 complete, 최상위 탭, 접근 제한 문구 감지 없음, iframe 0개였다.
상품 영역 1개에서 상품명·판매가·대표 이미지 자동 추출이 기록되었다.
로드된 화면 이미지 13개 중 호스트 등 기본 조건을 통과한 후보는 12개였고,
11개가 최종 상품 이미지 범위에서 제외되었다. 상세 영역과 리뷰 영역은 0개였다.

따라서 이 관찰에서 전체 로딩 실패, iframe, 상품명 추출 실패를 원인으로 볼 수 없다.
단, document complete는 동적 자료 로딩 완료를 보증하지 않는다.
파일에는 DOM 구조가 없으므로 제외된 11장이 상세 이미지인지, 추천·후기 사진인지 확정할 수 없다.
실제 상세/리뷰 영역의 선택자와 실패 조건도 이 파일만으로 확정할 수 없다.

## 코드에서 확인한 제한 및 이번 변경

- 기존 추가 이미지 탐색은 대표 이미지 조상 2단계까지만 탐색했다. 최대 6단계로 넓히되 상품 제목·다른 상품 링크·추천/상세/리뷰 영역을 만나면 중단한다.
- 상세 영역은 기존 선택자와 제한된 제목/tabpanel 표시에 의존했다. 표시된 '상품정보/상품상세/상세설명' 표지의 동일 문서 fragment, aria-controls, aria-labelledby 연결을 따라간다.
- 리뷰 영역은 selected ARIA 탭 또는 제목+정렬 버튼의 조합에 의존했다. 동일 문서의 '리뷰/구매평/상품평' 링크가 명시적으로 가리키는 표시 영역도 읽는다. 명시적으로 선택 해제된 탭, 숨긴 패널, 다른 상품/페이지의 링크는 사용하지 않는다.
- 기존 리뷰 정렬 탐색에서 링크 형태 컨트롤과 '랭킹순' 표시도 인식한다. 이것은 상품 추천 순위를 생성하는 기능이 아니다.
- 리뷰 본문은 기존 명시 본문 요소 또는 날짜+평점이 있는 카드의 본문 문단만 읽는다. 작성자나 일반 안내를 전체 영역에서 긁어오지 않는다.
- 열린 리뷰 영역 사진을 상품 이미지에서 제외하는 기존 방어를 유지한다. 대표·추가·상세 역할과 사용 권한 미확인은 유지한다.
- 상품명·판매가 탐색 로직, 시즌 추천, 상품 저장·영상 제작·Windows 실행 파일은 변경하지 않는다.

이는 명시적인 DOM 관계에 대한 개선이며 실제 브랜드스토어 구조를 확인한 수정은 아니다.
연결 정보가 없는 불명확한 영역은 계속 미확인으로 남긴다. 무작위 CSS 선택자를 추가하지 않았다.

## 개인정보 없는 구조 진단

새 진단은 최대 화면 이미지 24개, 이미지별 조상 7단계의 태그 종류·이미지/제목 개수·이미 인식한 상세/리뷰 영역 포함 여부를 기록한다.
최대 30개의 상세/리뷰 표지에 태그·선택 여부·aria-controls/fragment 존재 여부·화면 표시 여부·조상 태그 3단계를 기록한다.
HTML, 실제 본문, class/id 값, 링크 주소, 이미지 주소, 작성자, 로그인 정보는 구조 진단에 기록하지 않는다.
태그는 고정 목록으로 제한하고 가져오기에서도 알 수 없는 필드는 버린다.
기존 진단의 플랫폼·상품 번호·수집 카운터는 그대로 유지한다. 진단은 자동 전송하지 않는다.
상품 자료 JSON과 달리 진단 파일에는 상품 설명/구매평 원문이 포함되지 않는다.

## Windows에서 다시 확인

1. 웹앱을 종료하고 기존 폴더와 data를 백업한다. 새 브랜치 코드를 적용한다.
2. '처음 설치하기.cmd'로 변경된 앱을 다시 빌드하고 '쇼핑클립 시작하기.cmd'를 실행한다.
3. 기존 '상품 가져오기' 즐겨찾기를 삭제하고 앱에서 새 버튼을 등록한다. 팝업 버전이 **2026-10-28.4**인지 확인한다.
4. 실제 브랜드스토어 상품에서 직접 선택 없이 실행해 상품명·가격·대표 이미지 유지 여부를 확인한다.
5. 상세정보/구매평을 직접 열고 해당 자료가 화면에 보이도록 한 뒤 다시 읽는다. 북마클릿이 탭을 자동 클릭하거나 페이지를 자동 스크롤하지 않는다.
6. 상세·리뷰 영역이 계속 0이면 '진단 파일 저장'으로 새 파일을 전달한다. 서로 다른 화면에서 각각 저장하면 비교할 수 있다.
7. 다시 읽기는 현재 화면의 새 관찰로 교체한다. 이전 화면에서 수집한 이미지를 자동 누적하는 기능은 이번 범위에 포함하지 않았다.

자료를 수집했다는 사실은 광고에 재사용할 권한이 있다는 뜻이 아니다.

## 검증 범위

합성 DOM 테스트로 연결된 영역, 숨긴/다른 상품 영역 제외, 후기 사진 제외, 중첩 갤러리, 구조 진단 개인정보 차단을 확인한다.
사용자 진단 파일은 실제 관찰 자료지만 실제 페이지 HTML은 아니다.
실제 브랜드스토어·쿠팡 운영 페이지와 Windows 크롬에서 이번 버전 실행은 검증하지 못했다.

실행 결과: 전체 147개 테스트 파일 / 1,504개 테스트 통과, TypeScript 검사 및 프로덕션 빌드 통과. 변경 파일 ESLint 오류 없음. 별도 Chromium 합성 브랜드스토어 페이지에서 직접 선택 0회로 대표·추가·상세 이미지 및 리뷰 본문 수집, 후기 사진·광고 제외와 비공개 상태/쿠키/자동 fetch 미사용을 확인했다. 실제 운영 페이지 성공을 뜻하지 않는다.
